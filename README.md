# Market Neurons (Next.js App Router)

This project has been migrated from static HTML into a Next.js App Router structure while preserving the original design and behavior.

## Routes

- `/` → legacy dashboard page
- `/fertilizers` → legacy fertilizers page
- `/report` → legacy report page

## Run

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open:

```text
http://localhost:3000
```

## Build for production

```bash
npm run build
npm run start
```
